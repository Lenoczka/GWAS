# Поиск ассоциаций между генотипом и фенотипом (GWAS) + расчёт полигенного риска (PRS)

 
Полный цикл анализа Genome-Wide Association Study (GWAS) для ишемической болезни сердца (ИБС) на данных PennCath из https://github.com/tabpeter/reproduce_plmmr_manuscript, включая контроль качества, коррекцию на стратификацию популяции, логистическую регрессию и вычисление полигенного риска.

---

## 📌 Аннотация

В рамках проекта реализован паплайн предобработки генетических данных (QC), полногеномный ассоциативный анализ с учётом главных компонент и пола, а также расчёт полигенного риска (PRS) для пациентов с ИБС. Проект демонстрирует практическое применение PLINK и визуализации результатов.

---

## 🧬 Структура пайплайна

### 1️⃣ Контроль качества (QC)

- **Фильтрация пропусков** (`--geno 0.1`, `--mind 0.1`) – удаление SNP и образцов с >10% missing данных.
- **Оценка гетерозиготности** (`--het`) – поиск аномальных образцов (контаминация/инбридинг) с последующим удалением выбросов (скриптом `het_outliers.txt`).
- **Фильтрация по частоте минорного аллеля** (`--maf 0.01`) – исключение редких вариантов.
- **Проверка равновесия Харди–Вайнберга** (`--hwe 1e-6`) – удаление SNP с сильным отклонением от HWE (p < 1e-6).
- **Оценка скрытого родства** (`--genome`, `--min 0.2`) – поиск пар с PI_HAT ≥ 0.2. При обнаружении родственников формируется файл `samples_to_remove.txt` (удаляется второй индивид из пары).

### 2️⃣ Учёт популяционной стратификации (PCA)

- Выполнен PCA методом главных компонент (`plink19 --pca`).
- На графике PCA обнаружены обособленные кластеры → использование первых двух ПК в качестве ковариат для корректировки результатов GWAS.

### 3️⃣ Полногеномный ассоциативный анализ (GWAS)

- **Модель:** логистическая регрессия (case–control).
- **Коррекция:** первые 2 главные компоненты + **пол (sex)** как ковариата.
